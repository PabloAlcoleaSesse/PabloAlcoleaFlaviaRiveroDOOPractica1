# PabloAlcoleaFlaviaRiveroDOOPractica1

Ejercicio donde el usuario tiene que proporcionar una serie de datos sobre las distintas categorias de Filatelia y Numismática y el programa guardará esas respuestas.
Además el usuario puede pedir estas respuestas (precio total, los sellos y monedas totales o la rareza media de la colleción) al elegir las opciones 3,4,5 o 6.
